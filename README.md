# 🧹 お手伝い記録アプリ

## 📖 概要
子供のお手伝いを楽しく管理・記録できるWebアプリケーションです。
お手伝いをしてポイントを貯め、貯まったポイントをお小遣いやご褒美と「精算」する仕組みで、子供のモチベーションアップをサポートします！面倒な会員登録やログインは不要で、ブラウザだけですぐに使い始められます。

🌐 アプリはこちらからアクセス:

https://omuma.github.io/otetsudai/

## ✨ 主な機能
#### お手伝い項目のカスタマイズ
・お手伝いの内容（項目名）と、達成した際にもらえる付与ポイントをご家庭のルールに合わせて自由に設定・追加できます。

#### ポイント記録機能
・設定したお手伝いを達成した記録をつけると、現在のポイントが加算されていきます。

#### かんたん精算機能
・「精算」ボタンを押すと、貯まったポイントが支払い済みとして記録され、現在の所持ポイントから減算されます。お小遣い日やご褒美をあげるタイミングで便利に使えます。

#### 記録のクリア・削除
・不要になった項目や、これまでの記録をリセットしたい場合は、画面上から簡単に削除・クリアが可能です。

#### 💻 データ保存について（技術仕様）
ブラウザ完結（データベース不要）

本アプリは外部のデータベースを使用していません。記録されたお手伝い履歴やポイントのデータは、すべてご利用のブラウザのストレージ（ローカルストレージ）に保存されます。
不要になった項目や、これまでの記録をリセットしたい場合は、画面上から簡単に削除・クリアが可能です。

## 🚀 使い方
以下のURLにアクセスします。
https://omuma.github.io/otetsudai/

はじめに、やってほしい「お手伝いの項目」と「もらえるポイント」「子供の名前」を設定します。
子供がお手伝いをしてくれたら、アプリから記録をつけてポイントを貯めます。
お小遣いやご褒美と交換する際に、「精算」ボタンを押してポイントを消費・支払い記録をつけます。
ご不明な点や改善要望などがあれば、ぜひフィードバックをお願いします！
